## 控件（槽）
```信号
clicked() —— 按钮被点击时触发（最常用）
clicked(bool) —— 点击时带复选框状态（如果按钮可选中）
pressed() —— 鼠标按下时触发
released() —— 鼠标释放时触发
toggled(bool) —— 按钮状态切换时触发（适用于可选中按钮）
```
## 输入框（）

echoMode 取值（你截图中的）


值	说明
Normal	正常显示输入字符（默认）
NoEcho	不显示任何字符（常用于密码场景，完全不回显）
Password	密码模式，显示为密码掩码字符（如 •）
PasswordEchoOnEdit	编辑时短暂显示真实字符，失去焦点后变成密码掩码

# 电子时钟
`#include <QTime>`//时间头文件
##电子时钟ui控件设置
```
ui->lcdNumber->setDigitCount(8);
    ui->lcdNumber->setSegmentStyle(QLCDNumber::Filled);
    QTimer *timer = new QTimer(this);
    connect(timer, &QTimer::timeout, this，&MainWindow::updateTime);
    timer->start(1000);
    updateTime();
    setWindowTitle("电子时钟");
```

## 获取时间函数，并更新到 LCD 显示屏上。
```
void MainWindow::updateTime()
{
    QTime time = QTime::currentTime();
    ui->lcdNumber->display(time.toString("hh:mm:ss"));
}
```
