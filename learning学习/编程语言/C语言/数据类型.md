# 基础定义
 数据类型：用来规定内存中一块空间的存储规则，约束数据的取值范围、占用字节、运算方式、符号属性，编译器依靠类型分配内存、校验运算合法性。
 简单说：告诉CPU这块内存存的是整数/小数/字符，占多少空间，能不能存负数。


## 字符型 char
 • signed char：有符号，范围 -128 \sim 127；存传感器偏移量、小量程数值
 • unsigned char：无符号，范围 0 \sim 255；寄存器读写、I2C字节、缓冲区（无人机寄存器读写必用）
 - unsigned char reg_h = I2C_Read(ACCEL_XOUT_H); // 读取MPU6050高8位
## 短整型 short 
> int 16_t:      -32768 \+32767 ,MPU6050原始16位传感器数据专用
> uint 16_t     0 \65535,；PWM计数值、定时计数器(定时器为 16 位或 32 位定时器，16 位计数为 65536)
## 整型 int(32 位，4 字节)
 • int32_t：有符号大范围整数，PID积分累加、姿态积分运算
 • uint32_t：无符号，寄存器地址、定时周期、时间戳
## 长整型long long（64位，8字节）
int64_t / uint64_t

## 浮点型（小数，姿态解算核心）
• float 单精度浮点（4字节）：飞控主力，角度、PID系数、滤波运算、姿态解算（Mahony算法全靠float）
• double 双精度浮点（8字节）：精度更高，运算极耗MCU性能，STM32F1无硬件浮点，不推荐无人机使用

55. 四、有符号 vs 无符号核心区别（飞控高频踩坑点）
56. 
57. 1. 最高位：有符号数最高位是符号位，1代表负数；无符号全部用来存数值
58. 
59. 2. 运算风险：有符号与无符号混合比较会出错；陀螺仪负数偏移、加速度反向数值必须用有符号int16_t
60.
