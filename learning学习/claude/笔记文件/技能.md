#### 二：钩子 Hook
	**痛点一：忘了存档。** 自动化它：
我想创建一个钩子（hook）：每当一个新功能开发完成并测试通过后，自动更新 CLAUDE.md 文件记录进度。
触发方式选 **stop hook**（每轮结束自动检查）。
	**痛点二：AI 说”做完了”，其实没做完。** 
装个验收员：帮我创建一个 hook：在你准备结束任务前做交付验收。规则：如果本轮修改了代码、配置或文档，但没有测试过，或者检查发现还有待办事项没完成——不允许结束，继续工作直到验证通过。
从此每次收工前强制自查，“虚标完成”会少很多。可挂的节点还有：调用工具前后、子代理结束前、上下文压缩前后。
## 三：子代理 Subagent
*将单独的任务交给子代理可以高效进行工作*
案例：
帮我创建两个子代理：第一个叫"代码审查员"，专门找代码里的 bug 和质量问题；第二个叫"安全审查员"，专门检查应用的安全漏洞。
创建过程它会问几个选择，建议：
- 项目还是全局？
只为这个项目服务选 project
- 工具权限？
查资料类只给只读；要干活就全给
- 模型？
查证类 Sonnet 够了，省额度
- 记忆存哪？
跟项目走选 project scope
生效后：并行运行两个审查员，检查灵感日报这个项目，给我合并报告。两个 AI 同时审查互不干扰，报告出来说句”修复主要问题”收工。
⚠ **每新增一个子代理，回头让小队长认识它**：
查看我现有的所有子代理和它们的职责，更新 CLAUDE.md 里的任务路由规则：什么任务委派给谁、什么任务不委派、判断原则是什么。

####  四：通往外部世界：连接器 / MCP / CLI
CLI 很适合补齐具体工具能力。安装时直接说：帮我安装 XX CLI，并告诉我每一步怎么操作。值得装的：
- **Vercel CLI**：部署上线
- **Google Workspace CLI**：操作 Docs / Sheets / Gmail
- **Firecrawl CLI**：爬网页
- **ffmpeg / whisper**：视频剪辑 / 语音转文字，视频流水线的地基
