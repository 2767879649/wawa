1. 什么是函数指针，什么是指针函数
*函数指针*：指向一个函数的指针
*指针函数*：返回值是指针的函数
2. *指针的大小*：跟编译器系统结构的位数有关，32 bit 是 4 位，64 bit 是 8 位
3. *sizeof 和 strlen 的区别*
sizeof 得到的是内存的大小，strlen 得到的 是字符串的长度
sizeof 是运算符，strlen 是函数
sizeof 可以计算数据类型的大小，strlen 可以计算字符串的长度，不包括末尾的\0 结束符
4. *数组指针*：一个指向数组的指针，本质是一个指针
*指针数组*：在一个数组里，里面的成员全是指针
5. *c 语言内存分配的方式*：1.静态区分配 (全局变量，静态变量)2.栈上分配(平时函数中定义的变量) 3. 堆上分配(malloc 申请的)
6. *struct 结构体*：不同成员不同地址，内存分配存在字节对齐，根据编译器的位数，4 位对齐或者 8 位对齐，不足 4 位，补齐 4 位
*union 联合体*：所有成员共用一个地址，内存大小为成员最大的
7. *野指针*：指向不可用内存，未知地址，未初始化的指针，数组越界
8. *数组和链表*：数组里边变量的地址是连续的，链表是不连续的，数组通过下标进行访问，链表的访问需要遍历找到位置；
9. *volatile 的作用*：让变量必须真实的从内存中读写，不会被编译器优化；*哪些场景必须使用*：1.中断和函数共用的变量 2.改变寄存器的值 3.RTOS 中共享的标志变量 4. DMA 相关的变量 ；*总结*:需要不停的更改的变量，需要这个 volatile
10. *c 语言区*：代码区，静态区，常量区,栈，堆；
代码区：存放函数或机械指令；
静态存储区：全局变量，静态变量；
常量区：存放不会被修改的数据；
栈：局部变量，函数参数
堆：通过 malloc，calloc，realloc 动态申请的变量
11. *指针和数组的区别*：数组是一块连续的内存，可以存放相同的变量，指针里存放的是地址，指针可以指向数组；
12. *堆和栈的区别*：栈是在程序一开始就设定好的，一开始就存在的，而堆是可以在程序中动态申请的；栈和栈是独立的，数据是不共享的，堆中的数据是共享的
13. *内存泄漏怎么排查*：1. 先检查代码，malloc 申请动态变量后，有没有 free释放， 释放有没有完成，可以记录堆的申请次数 2. RTOS 中使用堆检测的钩子函数，查看堆的使用情况；
14. *结构体字节对齐规则*：如果设置为4 位对齐，相同的变量会补在内存后面，不同的变量不足 4 位会补齐 4 位；结构体的大小也看变量的创建先后；
15. *pragma pack*  ：改变结构体/联合体成员的最大对齐边界，精准控制内存大小；
16. UART 是异步点对点，两个设备之间进行通信；I 2 C 是同步半双工，两根线之间进行通信，可以多主机多从机，速度比 UART 快，缺点是功耗较大；SPI 同步全双工通信，一个主机连接多个从机，通信速度快，缺点是需要的线多
17. *I 2 C* 的停止位和开始位都是在 SCL 高电平之间，SDA 发生变化，数据位是在 SCL 低电平之间，SDA 发生改变，在 SCL 高电平之间进行数据读取；死锁是因为从机拉低 SDA 或者 SCL不放，导致没有开始停止位，通信信号不同步，也可能是上拉太大，没有检测到 SDA 低电平；上拉电阻不能太小，也不能太大，都导致检测不到上升或下降沿，太小，导致灌电流超标，一直处于高电平，也不能太大，太大导致上升沿太慢，可能检测的一直是低电平
18. *PWM* 是用定时器产生固定周期的方波，改变高电平或者低电平的占空比，来控制 PWM 的脉冲宽度，它有一个 OC 比较通道，通过这个通道来比较计数值和 CCR 的大小，频率是由 PSC 和 ARR 决定的，占空比是由 CCR 决定的
19. *ADC* 采样精度受什么影响：受到外部温度，噪声，采样时间，分辨率的影响，内部可能是电压，或者硬件设备的
20. *DMA* 在外设和内存之间进行数据搬运，不需要 CPU 的直接参与，可以提高 CPU 运行效率，适合大量，高速的数据运输；使用场景：ADC 连续采样，加上 DMA 实现硬件自动采样，UART 数据收发，就是需要大量传输数据得到时候选择 DMA 进行，I 2 C，SPI 进行数据传输；中断和 DMA：中断时由 CPU 主要参与的，让 CPU 进行数据搬运，DMA 只有在转运开始或者结束的时候进行参与 
21. *独立看门狗*：是在计数器减到 0 之前喂狗就行，窗口看门狗必须在 设定的窗口之间进行喂狗，不能太早或者太晚；
22. *RTOS*：进行时间片的轮转，在同优先级的情况下，两个任务之间交替进行，中断优先级高的先执行，协作式调度，任务可以主动让出 CPU 切换任务；*优先级反转*：高优先级的任务等待互斥锁进行，有互斥锁的任务，被另一个任务抢占,无法释放锁，高优先的任务被堵塞；*解决*：在任务进行期间关闭中断，不让抢占，或者优先级继承，低优先级暂时继承高优先级，还有挂起调度器，不让任务切换
23. *信号量*：可以用来资源或者事件计数；*互斥量*：用来保护共享资源；队列可以传输数据；事件组：可以等待多个事件

25. 任务栈溢出检测：通过钩子函数检测溢出，用余量估计栈的大小，
