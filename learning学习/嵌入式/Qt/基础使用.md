# UI控件基本操作
ui->控件名字
- ->setText("")//设置ui显示文本
- ->setIcon(QIcon "xxxx路径");//图片
```
ui->控件对象名->setText("显示的文本");     // 设置显示文字
ui->控件对象名->setIcon(QIcon("图片路径")); // 设置图标，支持资源文件(:/xxx.png)
```

# 常用控件信号（槽）

| 信号            | 触发时机                |
| ------------- | ------------------- |
| clicked()     | 按钮被点击时触发（最常用）       |
| clicked(bool) | 点击时带复选框状态（如果按钮可选中）  |
| pressed()     | 鼠标按下时触发             |
| released()    | 鼠标释放时触发             |
| toggled(bool) | 按钮状态切换时触发（适用于可选中按钮） |

# 输入框（QLineEdit）回显模式
==echoMode==== 

| 模式                   | 说明                    |
| -------------------- | --------------------- |
| `Normal`             | 正常显示输入的字符（默认）         |
| `NoEcho`             | 完全不显示任何字符             |
| `Password`           | 显示为密码掩码字符（如 •）        |
| `PasswordEchoOnEdit` | 编辑时短暂显示真实字符，失去焦点后恢复掩码 |
|                      |                       |

> 设置方式：`ui->lineEdit->setEchoMode(QLineEdit::Password);`
