# 定时器
### 硬件定时器触发
1. `hw_timer_t *timer = NULL;` // 创建定时器指针
2. `timer = timerBegin(0, 80, true);` //初始化定时器，true 为向上计数，false 为向下计数
3. `timerAttachInterrupt(timer, timer_interrupt, true);` //将定时器指针与定时器中断函数绑定，true 为边沿检测，false 为电平检测
4. `timerAlarmWrite(timer, 1000 * 1000, true)` //设置定时器模式，true 为开始自动重装
5. `timerAlarmEnable(timer)`//启动定时器
### 软件定时器触发
使用 ESP 32 自带的 Ticker 库
1. `Ticker timer;`创建定时器对象
2. 创建回调函数
3. ` timer.attach(0.5, timer_interrupt, GPIO_2);` 配置定时器，0.5 秒触发一次，回调函数，可以传递参数，也可以不传
