# 模块输出(喇叭)
蓝牙通过 **AVRCP** 协议进行信息传输，通过 AVRCP 元数据来进行数据传输；
AVRCP 元数据属性：
|属性宏定义|ID (掩码值)|含义|
|`ESP_AVRC_MD_ATTR_TITLE`|`0x01`|正在播放曲目的**标题**（歌曲名）|
|`ESP_AVRC_MD_ATTR_ARTIST`|`0x02`|曲目的**艺术家**（歌手）|
|`ESP_AVRC_MD_ATTR_ALBUM`|`0x04`|**专辑名称**|
|`ESP_AVRC_MD_ATTR_TRACK_NUM`|`0x08`|曲目在专辑中的**序号**（第几首）|
|`ESP_AVRC_MD_ATTR_NUM_TRACKS`|`0x10`|专辑中的**曲目总数**|
|`ESP_AVRC_MD_ATTR_GENRE`|`0x20`|曲目的**流派**（如流行、摇滚）|
|`ESP_AVRC_MD_ATTR_PLAYING_TIME`|`0x40`|专辑的**总播放时长**（单位：**毫秒**）|
# 模块输入(麦克风)
