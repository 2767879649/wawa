# 介绍
- 使用 I 2 S 总线进行接收与发送数据，I 2 S 是音频专用总线，ESP 32 的I 2 s 总线共有两个通道
`esp_err_t err = i2s_write(I2S_OUT_PORT, pcm16, sizeof(pcm16), &bytesWritten, portMAX_DELAY);` //I 2 S 发送信息
`esp_err_t err = i2s_read(端口号, 缓存区, 缓存区大小, 实际接收到的大小, portMAX_DELAY);` //I 2 S 读取信息
esp_err_t 本质是 int
**PDM 模式**：无论是发送（TX）还是接收（RX），**I2S 硬件都只支持 16 位宽度的 PCM样本数据**
- 接收：通过 LDM麦克风芯片得到的数据，需要 I 2 S 进行处理，采样位 16 位要比 32 位多一倍的样本数量,接收的数据是一般是左对齐的，<font color="#4bacc6">高位为有效数据</font>
- 发送：功放芯片的位数不固定，根据得到的数据决定选择的位数 
# 模块输出(喇叭)
I 2 S 配置为输出模式，和麦克风设置不同的端口号
## 蓝牙音响的工作原理
蓝牙通过 **AVRCP** 协议进行信息传输，通过 AVRCP 元数据来进行数据传输；
AVRCP 元数据属性：
|属性宏定义|ID (掩码值)|含义|
|`ESP_AVRC_MD_ATTR_TITLE`|`0x01`|正在播放曲目的**标题**（歌曲名）|
|`ESP_AVRC_MD_ATTR_ARTIST`|`0x02`|曲目的**艺术家**（歌手）|
|`ESP_AVRC_MD_ATTR_ALBUM`|`0x04`|**专辑名称**|
|`ESP_AVRC_MD_ATTR_TRACK_NUM`|`0x08`|曲目在专辑中的**序号**（第几首）|
|`ESP_AVRC_MD_ATTR_NUM_TRACKS`|`0x10`|专辑中的**曲目总数**|
|`ESP_AVRC_MD_ATTR_GENRE`|`0x20`|曲目的**流派**（如流行、摇滚）|
|`ESP_AVRC_MD_ATTR_PLAYING_TIME`|`0x40`|专辑的**总播放时长**（单位：**毫秒**）|
# 模块输入(麦克风)
ESP 的 I 2 S 配置为 PDM 模式
PDM 模式下只有帧时钟和数据引脚(<font color="#9bbb59">没有位时钟</font>)
引脚为：ClK 和 DATA
在线识别需要接口的APPID，APISecret，APIKey
## 语音识别流程
### 1. 初始化 I 2 S ，音频模块麦克风输入
- 配置 I 2 S 为 PDM 模式，设置为主机输入模式
- 采样率为 16000 HZ
- 引脚配置 CLK 和 DATA
- 通过麦克风输入，读取音频，保存 PCM 原始数据
- (可以进行偏置和限幅处理)
### 2. WiFi 初始化
- WiFi.mode(WIFI_STA);        // 设置为STA模式
-     WiFi.begin(ssid, password); // 开始连接
- 连接完成后后就要通过 NTP时间获取鉴权 URL 了
### 3.获取鉴权 URL(<font color="#c00000">重点</font>)
- 同步 NTP 时间，鉴权需要准确的时间
- 拼接鉴权签名，获取鉴权原文
- 将原文进行 HMAC—SHA 256 加密计算
- 然后进行 Base 64 编码，得到加密后的签名参数
- 拼接获取Authorization原文
- 将Authorization原文进行 Base 64 编码，得到Authorization 参数
- 构造完整的URL
### 4. 进行WebSocket连接
- 通过获取的 URL 与服务器进行连接
- 注册回调函数
- 通过回调函数处理识别信息
### 5. 读取音频数据
- 将音频数据发送到服务端
