# 模块输出(喇叭)
蓝牙通过 **AVRCP** 协议进行信息传输，通过 AVRCP 元数据来进行数据传输；
AVRCP 元数据属性：
|属性宏定义|ID (掩码值)|含义|
|`ESP_AVRC_MD_ATTR_TITLE`|`0x01`|正在播放曲目的**标题**（歌曲名）|
|`ESP_AVRC_MD_ATTR_ARTIST`|`0x02`|曲目的**艺术家**（歌手）|
|`ESP_AVRC_MD_ATTR_ALBUM`|`0x04`|**专辑名称**|
|`ESP_AVRC_MD_ATTR_TRACK_NUM`|`0x08`|曲目在专辑中的**序号**（第几首）|
|`ESP_AVRC_MD_ATTR_NUM_TRACKS`|`0x10`|专辑中的**曲目总数**|
|`ESP_AVRC_MD_ATTR_GENRE`|`0x20`|曲目的**流派**（如流行、摇滚）|
|`ESP_AVRC_MD_ATTR_PLAYING_TIME`|`0x40`|专辑的**总播放时长**（单位：**毫秒**）|
# 模块输入(麦克风)
ESP 的 I 2 S 配置为 PDM 模式
PDM 模式下只有帧时钟和数据引脚(<font color="#9bbb59">没有位时钟</font>)
引脚为：ClK 和 DATA
在线识别需要接口的APPID，APISecret，APIKey
## 语音识别流程
### 1. 初始化 I 2 S ，音频模块麦克风输入
- 配置 I 2 S 为 PDM 模式，设置为主机输入模式
- 采样率为 16000 HZ
- 引脚配置 CLK 和 DATA
- 通过麦克风输入，读取音频，保存 PCM 原始数据
- (可以进行偏置和限幅处理)
### 2. WiFi 初始化
- WiFi.mode(WIFI_STA);        // 设置为STA模式
-     WiFi.begin(ssid, password); // 开始连接
- 连接完成后后就要通过 NTP时间获取鉴权 URL 了
### 3.获取鉴权 URL(<font color="#c00000">重点</font>)
- 同步 NTP 时间，鉴权需要准确的时间
- 拼接鉴权签名，获取鉴权原文
- 将原文进行 HMAC—SHA 256 加密计算
- 然后进行 Base 64 编码
- 拼接获取Authorization原文
- 将Authorization原文进行 Base 64 编码
- 构造完整的URL
### 4. 进行WebSocket连接
- 通过获取的 URL 与服务器进行连接
- 通过回调函数处理识别信息(回调函数需要注册)
