# 函数
## 延迟函数
`HAL_delay` 
## 引脚输出
`HAL_GPIO_WritePin(GPIOA, GPIO_PIN_0, GPIO_PIN_RESET);` //更改电平
`HAL_GPIO_TogglePin(GPIOA, GPIO_PIN_0);` //翻转电平状态
## 获取引脚电平
`HAL_GPIO_ReadPin(GPIOA,GPIO_PIN_1)==SET` //获取电平状态
## NVIC
`HAL_NVIC_SetPriority(EXTI0_IRQn, 10, 0);` //10 是中断优先级，0 是响应优先级
`HAL_NVIC_EnableIRQ(EXTI0_IRQn); ` //NVIC 使能
# 串口通信
## printf串口重定向
==需要引入"stdio.h"头文件==
```c
int fputc(int ch,FILE *f)
{
    HAL_UART_Transmit(&huart1,(uint8_t*)&ch,1,HAL_MAX_DELAY);
    return ch;
}
```
## 串口发送
`HAL_UART_Transmit(&huart1,recv,10,1000);` //发送zi'fu'c'ch
`HAL_UART_Receive(&huart1,recv,10,1000);`
