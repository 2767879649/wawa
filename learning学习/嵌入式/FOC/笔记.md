### 有感
#### 一、FOC 基本原理
##### 1.1 核心思想
把三相交流量通过坐标变换“搬到”随转子旋转的 dq 坐标系里，变成两个直流量 Id（励磁）、Iq（转矩），再用 PI 分别控制——交流问题变成直流问题。
##### 1.2 坐标变换链
```
三相 abc ──Clarke──> 静止 αβ ──Park──> 旋转 dq ──PI──> Ud,Uq
                                                        │
三相 PWM <──SVPWM── 静止 αβ <──反Park── dq(Ud,Uq) <─────┘
```
**Clarke（恒幅值）**：
```
Iα = Iu
Iβ = (Iu + 2Iv)/√3
```
**Park**（θ 为电角度）：
```
Id =  Iα·cosθ + Iβ·sinθ
Iq = -Iα·sinθ + Iβ·cosθ
```
**反 Park**：
```
Uα = Ud·cosθ - Uq·sinθ
Uβ = Uq·cosθ + Ud·sinθ
```

### 无感
