# 问题
1. 时钟树配置为 170 MHZ；
2. 栅极驱动芯片自带死区配置(可以设置死区为 0)
3. SVPWM 计算时间应该是 2*ARR；
4. 在 24 v 母线电压的情况下，SVPWM 的线性区上线是 VBus/√3=13.86 V，是逆变器能输出的最大不失真相电压幅值
5. 空载最高机械转速=p⋅ψf​13.86，**ψf​：**永磁体磁链**这是永磁同步电机（PMSM）最核心的物理参数之一，代表了电机内部永磁体产生的磁场强度。​
# Matlab 仿真问题
1. 电机的极对数需要注意配置，极对数不对可能会出现速度和角度是正弦波变化的情况
2. 死区补偿可以 根据定时器 ARR 进行 配置。
3. 从电机中得到的速度单位是 rad/s，角度是机械角度。
4. 速度环的目标速度与实际速度单位需要一直，$rad/s*30/pi=r/m$。
