# 开发环境搭建

## 一、Ubuntu 开发环境

### 1.1 基础依赖库安装

```bash
# 基础编译工具
sudo apt-get install build-essential cmake cmake-qt-gui git -y

# OpenCV 依赖
sudo apt-get install libgtk2.0-dev pkg-config libavcodec-dev \
  libavformat-dev libswscale-dev libjpeg-dev libpng-dev libtiff-dev \
  libjasper-dev libdc1394-22-dev libv4l-dev libtbb-dev -y

# Python 支持
sudo apt-get install python-dev python-numpy -y

# 多媒体支持
sudo apt-get install ffmpeg libxine2-dev libgstreamer1.0-dev \
  libgstreamer-plugins-base1.0-dev -y

# Qt 支持
sudo apt-get install qtbase5-dev libqt4-dev -y

# 其他
sudo apt-get install libopenblas-dev doxygen libgphoto2-dev \
  libavresample-dev -y
```

### 1.2 交叉编译工具链

```bash
# 解压 ARM 交叉编译工具到 /opt
sudo tar -xf arm-2014.05-29-arm-none-linux-gnueabi-i686-pc-linux-gnu.tar.bz2 -C /opt

# 添加到 PATH
sudo gedit /etc/profile
# 加入: export PATH=$PATH:/opt/arm-2014.05/bin
```

### 1.3 OpenCV 3.4.5 安装

```bash
# 解压到 /opt
sudo tar -xf opencv-3.4.5.tar.gz -C /opt
sudo tar -xf opencv.tar -C /opt   # 预先编译好的版本

# 配置库路径
sudo gedit /etc/ld.so.conf.d/opencv.conf
# 加入: /usr/local/lib
sudo ldconfig

# 环境变量
sudo gedit /etc/bash.bashrc
# 加入:
# export PKG_CONFIG_PATH=/usr/local/opencv/lib/pkgconfig
# export LD_LIBRARY_PATH=/usr/local/opencv/lib
```

### 1.4 Qt 5.7.0 安装

```bash
sudo tar -xf Qt5.7.0.tar -C /usr/local
```

## 二、ARM 嵌入式平台环境

### 2.1 平台信息

- **开发板**: Tiny4412 (Samsung Exynos 4412, Cortex-A9 四核)
- **内存**: 1GB DDR3
- **存储**: SD 卡启动

### 2.2 SD 卡烧录 (U-Boot + Kernel)

```bash
# BL1 (一级引导)
sudo dd iflag=dsync oflag=dsync if=./E4412_N.bl1.bin of=/dev/sdb seek=1

# BL2 (二级引导)
sudo dd iflag=dsync oflag=dsync if=./bl2.bin of=/dev/sdb seek=17

# U-Boot
sudo dd iflag=dsync oflag=dsync if=./u-boot.bin of=/dev/sdb seek=49

# Linux Kernel
sudo dd iflag=dsync oflag=dsync if=./zImage of=/dev/sdb seek=1057
```

### 2.3 U-Boot 环境变量

```
set bootargs 'noinitrd root=/dev/nfs nfsroot=192.168.15.2:/home/zhu/driver/rootfs \
  ip=192.168.15.88:192.168.15.2:192.168.15.1:255.255.255.0::eth0:off \
  init=/linuxrc console=ttySAC0 lcd=S70'

set bootcmd 'fatload mmc 0 40008000 zImage;bootm 40008000'
save
```

**NFS 网络配置说明:**
- 192.168.15.2 → 主机 (NFS Server)
- 192.168.15.88 → 开发板 IP
- 192.168.15.1 → 网关
- 根文件系统通过 NFS 挂载，方便开发调试

### 2.4 NFS 服务配置

```bash
sudo apt-get install nfs-common nfs-kernel-server -y
sudo /etc/init.d/nfs-kernel-server restart
```

## 三、Qt 项目配置 (.pro 文件)

### 3.1 OpenCV 库链接配置

```qmake
# 头文件路径
INCLUDEPATH += /opt/opencv/opencv-3.4.5/install/include/opencv \
               /opt/opencv/opencv-3.4.5/install/include/opencv2 \
               /opt/opencv/opencv-3.4.5/install/include \
               /opt/opencv/opencv-3.4.5/install/include/opencv2/core \
               /opt/opencv/opencv_contrib-3.4.5/modules/face/include/opencv2/

# 动态链接所有 OpenCV 库
LIBS += /opt/opencv/opencv-3.4.5/install/lib/libopencv_*
```

## 四、摄像头设备节点

| 平台 | 摄像头设备号 |
|------|-------------|
| Linux 桌面 (x86) | `/dev/video0` (OpenCV 参数: `0`) |
| ARM 开发板 | `/dev/video15` (OpenCV 参数: `15`) |

```cpp
// 代码中的条件编译
#if ARCH == 1      // x86桌面
    capeture.open(0);
#elif ARCH == 2    // ARM平台
    capeture.open(15);
#endif
```

## 五、OpenCV Contrib Face 模块

人脸识别功能需要 `opencv_contrib` 中的 `face` 模块：

- 包含路径: `/opt/opencv/opencv_contrib-3.4.5/modules/face/include/opencv2/`
- 关键头文件: `face.hpp`, `face/facerec.hpp`
- 必须链接: `libopencv_face.so`
