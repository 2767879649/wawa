# Qt 核心知识

## 一、Qt 项目基本结构

### 1.1 最小 Qt 项目

```cpp
// main.cpp — 应用程序入口
#include <QApplication>
#include "widget.h"

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);  // Qt应用对象（必须有）
    Widget w;                     // 创建主窗口
    w.show();                     // 显示窗口
    return a.exec();              // 进入事件循环（阻塞）
}
```

### 1.2 .pro 工程文件结构

```qmake
QT       += core gui                     # Qt模块
greaterThan(QT_MAJOR_VERSION, 4): QT += widgets  # Qt5需要

TARGET = face_recognition                # 生成的可执行文件名
TEMPLATE = app                           # 应用程序模板

SOURCES += main.cpp widget.cpp setting.cpp  # 源文件
HEADERS += widget.h setting.h               # 头文件
FORMS   += widget.ui setting.ui             # UI文件
RESOURCES += source.qrc                     # 资源文件

INCLUDEPATH += ...   # 附加头文件路径
LIBS += ...           # 附加库文件
```

## 二、信号与槽 (Signals & Slots)

Qt 的核心通信机制，用于对象间的松散耦合通信。

### 2.1 基本语法

```cpp
// 连接信号和槽
connect(发送者, SIGNAL(信号名(参数)), 接收者, SLOT(槽函数(参数)));

// 实际示例
connect(timer, SIGNAL(timeout()), this, SLOT(showVideo()));
connect(&set, SIGNAL(backHome()), this, SLOT(on_backHome()));
```

### 2.2 自定义信号

```cpp
// 在头文件的 signals: 区域声明
class Widget : public QWidget
{
    Q_OBJECT           // 必须！启用元对象系统

signals:
    void back_mainWindow();   // 自定义信号
};
```

### 2.3 发射信号

```cpp
emit back_mainWindow();  // 发射信号，触发连接的槽函数
emit backHome();         // 信号可跨对象触发
```

## 三、QTimer 定时器

### 3.1 基本用法

```cpp
// 创建定时器
QTimer *show_time = new QTimer;
show_time->setInterval(10);  // 10毫秒间隔
connect(show_time, SIGNAL(timeout()), this, SLOT(showVideo()));
show_time->start();           // 开始计时

// 一次性定时器
QTimer::singleShot(2000, box, &QMessageBox::close);  // 2秒后关闭对话框
```

### 3.2 项目中的实际应用

```cpp
// 视频帧刷新定时器 (10ms ≈ 100fps理论值)
show_time = new QTimer;
show_time->setInterval(10);
connect(show_time, SIGNAL(timeout()), this, SLOT(showVideo()));
show_time->start();

// 识别启动定时器 (每1秒检查一次)
recognize_time = new QTimer;
connect(recognize_time, SIGNAL(timeout()), this, SLOT(start_Recognize()));
recognize_time->start(1000);

// 停止定时器
timer->stop();
```

## 六、Mat ↔ QImage 转换

这是 Qt + OpenCV 开发中最常用的转换：

```cpp
QImage Widget::Mat2Image(Mat image) {
    // BGR → RGB (OpenCV默认BGR，Qt使用RGB)
    cvtColor(image, image, CV_BGR2RGB);

    // 构造 QImage
    QImage src = QImage(
        (const unsigned char *)(image.data),  // 像素数据指针
        image.cols,      // 宽度
        image.rows,      // 高度
        image.step,      // 每行字节数（步长）
        QImage::Format_RGB888  // 24位RGB格式
    );
    return src;
}
```

### 另一种转换方式（直接构造）

```cpp
Mat frame2;
cvtColor(frame, frame2, COLOR_BGR2RGB);
QImage img((const uchar*)frame2.data,
           frame2.cols, frame2.rows,
           frame2.cols * frame2.channels(),  // 步长 = 宽 × 通道数
           QImage::Format_RGB888);
```

## 七、图片自适应显示

```cpp
// 按比例缩放图片到Label大小
QImage CameraManage::ScaleImage2Label(QImage qImage, QLabel* qLabel) {
    QImage qScaledImage;
    QSize qImageSize = qImage.size();
    QSize qLabelSize = qLabel->size();
    double dWidthRatio = 1.0 * qImageSize.width() / qLabelSize.width();
    double dHeightRatio = 1.0 * qImageSize.height() / qLabelSize.height();

    if (dWidthRatio > dHeightRatio) {
        qScaledImage = qImage.scaledToWidth(qLabelSize.width());
    } else {
        qScaledImage = qImage.scaledToHeight(qLabelSize.height());
    }
    return qScaledImage;
}

// 或者直接设置Label自适应
ui->label->setScaledContents(true);
```
