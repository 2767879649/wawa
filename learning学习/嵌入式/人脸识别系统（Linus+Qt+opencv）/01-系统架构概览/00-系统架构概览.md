# 人脸识别门禁系统 — 系统架构概览

## 项目简介

这是一个基于 **Linux ARM + Qt + OpenCV** 的嵌入式人脸识别门禁控制系统，来自信盈达（XYD）嵌入式培训课程。

## 系统拓扑

```
+-------------------------------+    UART (9600)     +------------------+
|  Tiny4412 ARM 主板 (Linux)    | <----------------> |  STM32F103 MCU   |
|                               |                    |                  |
|  Qt 应用程序:                  |   "open" 命令      |  门禁控制器       |
|  - 摄像头采集 (OpenCV)         | -----------------> |  - 串口接收       |
|  - 人脸检测 (Haar Cascade)     |                    |  - 步进电机       |
|  - 人脸识别 (LBPH)            |   0x01/0x02 状态   |  - PID 控制      |
|  - 用户信息录入                | <----------------- |  - 自动关门       |
|  - 模型训练                   |                    |  - 手动按键       |
|  - 串口通信                   |                    |  - LED/蜂鸣器    |
+-------------------------------+                    +------------------+
        |
        | 摄像头 /dev/video15 (ARM) 或 /dev/video0 (x86)
        v
   USB 摄像头
```

## 核心技术栈

| 层级 | 技术 |
|------|------|
| **操作系统** | Linux (ARM Linux on Tiny4412) |
| **GUI框架** | Qt 5.7.0 (Widgets) |
| **计算机视觉** | OpenCV 3.4.5 + opencv_contrib (face模块) |
| **人脸检测** | Haar Cascade (haarcascade_frontalface_alt/alt2.xml) |
| **人脸识别** | LBPHFaceRecognizer (局部二值模式直方图) |
| **关键点检测** | FacemarkLBF (68点人脸特征点) |
| **硬件平台** | Samsung Exynos 4412 (Cortex-A9), STM32F103ZE |
| **编译工具** | arm-2014.05 (arm-none-linux-gnueabi), GCC |
| **外设通信** | UART 串口 (9600 baud), USB 摄像头 |

## 软件架构

```
main.cpp                 -- Qt 应用入口
  └── Widget (主窗口)     -- 摄像头预览 + 识别结果显示
       ├── RECOGNIZE线程  -- 后台持续人脸识别
       ├── QTimer(10ms)   -- 视频帧刷新
       ├── QTimer(1000ms) -- 识别线程启动
       └── Setting (管理页) -- 人脸录入 + 模型训练
            └── QTimer(30ms) -- 预览刷新

face_gate_machine        -- Linux串口初始化
  └── Serial_Init()      -- 打开 /dev/ttySAC2

STM32 (独立工程):
  main.c → Data_Check()  -- 接收串口命令
         → PID_Compute() -- 步进电机PID控制
         → 按键/定时器    -- 手动/自动关门
```

## 编译模式切换

项目通过宏定义切换两种平台配置：

```cpp
#define ARCH_WIN  1   // x86 Linux桌面开发
#define ARCH_ARM  2   // ARM嵌入式目标
#define FACE  ALL_FUNC  // 全功能模式（含OpenCV）
```

- `ARCH_WIN`: 摄像头设备号为 `0`，分类器路径为 `/home/xyd/opencv/...`
- `ARCH_ARM`: 摄像头设备号为 `15`，分类器路径为 `/usr/share/OpenCV/haarcascades/...`

## 数据文件约定

| 文件 | 用途 | 格式 |
|------|------|------|
| `usr.txt` | 用户姓名注册表 | `编号;姓名` （如 `1;张三`） |
| `csv.txt` | 训练用图像索引 | `图片路径;标签编号` |
| `facemodel.xml` | LBPH训练好的模型 | OpenCV XML格式 |
| `TEMP/` | 拍照临时目录 | `.jpg` 文件 |
| `编号/` | 按用户编号存储的人脸图片 | 灰度 92×112 `.jpg` |

## 人脸识别流程

```
摄像头采集 → 灰度转换 → 直方图均衡化 → Haar级联人脸检测
→ 提取人脸ROI → 缩放到92×112 → LBPH预测 → 置信度判断
→ (成功) 查找姓名 → 显示结果 + 串口发送"open"
→ (失败) 显示"查无此人"或"请调整位置"
```

## 人脸录入流程

```
拍照(N张) → 检测每张照片中的人脸 → 提取人脸ROI
→ 缩放至92×112 → 按用户编号存到对应文件夹
→ 生成csv.txt → LBPH模型训练/更新 → 保存facemodel.xml
```
