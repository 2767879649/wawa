## 核心技术链

```
Qt 5.7 (GUI) → OpenCV 3.4.5 (视觉) → Linux (OS) → ARM Cortex-A9 (硬件)
                                              ↓
                                        串口 UART
                                              ↓
                                       STM32F103 (门控)
                                              ↓
                                         步进电机
```

## 关键算法

| 算法 | 用途 | OpenCV类 |
|------|------|----------|
| Haar Cascade | 人脸检测 | `CascadeClassifier` |
| LBPH | 人脸识别 | `LBPHFaceRecognizer` |
| FacemarkLBF | 人脸68点关键点 | `FacemarkLBF` |
| 直方图均衡化 | 图像增强 | `equalizeHist()` |
| PID控制 | 步进电机速度 | 自定义实现 |

## 关键参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 人脸检测 minSize | 90×112 | 最小人脸尺寸 |
| 人脸识别尺寸 | 92×112 | 统一缩放尺寸 |
| LBPH 置信度阈值 | 85 | 大于此值视为"查无此人" |
| 摄像头 (ARM) | `/dev/video15` | OpenCV设备号 15 |
| 摄像头 (x86) | `/dev/video0` | OpenCV设备号 0 |
| 串口 (ARM) | `/dev/ttySAC2` | 9600 baud |
| 视频刷新率 | 10ms | QTimer间隔 |
| 识别检查间隔 | 1000ms | 启动阶段检查文件 |
| UI分辨率 | 800×480 | ARM LCD |
