## 二、main.cpp — 应用入口

```cpp
#include "widget.h"
#include <QApplication>

int main(int argc, char *argv[])
{
    QApplication a(argc, argv);  // Qt应用对象
    Widget w;                     // 创建主窗口
    w.show();                     // 显示
    return a.exec();              // 进入事件循环
}
```

**要点:**
- `QApplication` 必须在所有Qt组件之前创建
- `a.exec()` 进入事件循环，程序在此阻塞直到窗口关闭
- 只创建了一个 `Widget` 窗口，`Setting` 在 Widget 内部创建

### 4.3 showVideo() — 视频帧处理

```cpp
void Widget::showVideo() {
    // 1. 获取一帧
    capeture >> resource;
    frame = resource.clone();

    // 2. 灰度转换 + 直方图均衡化
    cvtColor(frame, gray, CV_BGR2GRAY);
    equalizeHist(gray, gray);

    // 3. 人脸检测
    faceClassifier.detectMultiScale(gray, faces, 1.8, 3, 0,
                                    cv::Size(90, 112));

    // 4. 遍历检测结果
    for (size_t i = 0; i < faces.size(); i++) {
        if (faces[i].height > 0 && faces[i].width > 0) {
            myface = gray(faces[i]);      // 提取人脸ROI
            rectangle(frame, faces[i],
                      cv::Scalar(0, 0, 255), 1, 8, 0);  // 画框
            xx = faces[i].x;              // 记录坐标
            yy = faces[i].y;
        }
    }

    // 5. 转换为QImage并显示
    QImage res = Mat2Image(frame);
    ui->label->setPixmap(QPixmap::fromImage(res));
}
```

### 4.4 start_Recognize() — 启动识别

```cpp
void Widget::start_Recognize() {
    // 状态机：先检查 facemodel.xml，再检查 usr.txt
    if (file_stat == 0) {
        if (facemodel.open(QIODevice::ReadOnly | QIODevice::Text)) {
            file_stat++;  // 模型文件存在 → 状态1
        }
    }
    else if (file_stat == 1) {
        if (user.open(QIODevice::ReadWrite | QIODevice::Text)) {
            file_stat++;  // 用户文件存在 → 状态2
        }
    }
    if (file_stat == 2) {
        p_recognize.start();        // 启动识别线程
        recognize_time->stop();      // 停止检查定时器
    }
}
```

### 4.5 RECOGNIZE::run() — 识别主循环

```cpp
void RECOGNIZE::run() {
    while (1) {
        // 1. 等待检测到人脸
        if (myface.empty()) continue;

        // 2. 人脸缩放
        cv::resize(myface, face_test, cv::Size(92, 112));

        // 3. 检查人脸数量
        if (faces.size() == 0) {
            face_ui->label_result->setText("请调整位置");
            continue;
        }

        // 4. 加载模型并预测
        model = LBPHFaceRecognizer::create();
        model = Algorithm::load<LBPHFaceRecognizer>(xmlfile.toStdString());
        model->predict(face_test, predictLabel, predictConfidence);

        // 5. 置信度判断
        if (predictConfidence > 85) {
            face_ui->label_result->setText("查无此人");
        } else {
            // 6. 从 usr.txt 查找姓名
            while (!user.atEnd()) {
                line = user.readLine();
                usrlinenum++;
                if (usrlinenum == predictLabel) {
                    name = line.split(";")[1];
                    face_ui->label_result->setText("识别结果：" + name);
                    // 7. 发送开门命令
                    strcpy(buf, "open");
                    write(myserial, buf, sizeof(buf));
                    // 8. 接收响应
                    read(myserial, &r_buf, sizeof(buf));
                    if (r_buf == 0x01) { /* 门已开启 */ }
                }
            }
        }
    }
}
```

### 5.2 on_ButtonCsv_clicked() — CSV取样处理

完整流程：
1. 在 `usr.txt` 中添加新用户记录
2. 创建用户编号目录（如 `1/`）
3. 对 TEMP 中每张照片进行人脸检测
4. 裁剪人脸 → 缩放 92×112 → 灰度 → 保存
5. 生成 `csv.txt` 训练索引文件

### 5.3 on_ButtonTrain_clicked() — 模型训练

```cpp
void Setting::on_ButtonTrain_clicked() {
    // 1. 读取 csv.txt
    vector<Mat> images;
    vector<int> labels;
    while (!csv.atEnd()) {
        QString p = csv.readLine(128);
        QStringList qlist = p.split(";");
        images.push_back(cv::imread(qlist[0].toStdString(), 0));
        labels.push_back(qlist[1].toInt());
    }

    // 2. 训练或更新
    if (!QFile::exists("facemodel.xml")) {
        model = LBPHFaceRecognizer::create();
        model->train(images, labels);    // 首次训练
    } else {
        model = Algorithm::load<LBPHFaceRecognizer>("facemodel.xml");
        model->update(images, labels);   // 增量更新
    }

    // 3. 保存模型
    model->save("facemodel.xml");
}
```

## 九、数据流总结

```
录入阶段:
  摄像头 → TEMP/*.jpg → 人脸检测 → 编号文件夹/*.jpg → csv.txt → 模型训练 → facemodel.xml

识别阶段:
  摄像头 → 灰度+均衡化 → 人脸检测 → 人脸ROI(92×112) → LBPH预测 → usr.txt查名 → 显示 → 串口开锁

训练阶段:
  csv.txt → 读取images+labels → LBPHFaceRecognizer::train/update → facemodel.xml
```
