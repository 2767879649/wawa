# 串口通信与门禁控制

## 一、系统通信架构

```
Qt应用程序 (ARM Linux)          STM32F103 门控
    │                              │
    │  "open" 命令 ──────────────> │  开门
    │  <────────── 0x01 ───────── │  门已开启
    │  <────────── 0x02 ───────── │  门已关闭
    │                              │
    │  串口设备: /dev/ttySAC2      │  UART4 (PC10-TX, PC11-RX)
    │  波特率: 9600                │  波特率: 9600
    │  数据位: 8, 无校验, 1停止位  │  8N1
    └──────────────────────────────┘
```

## 二、Linux 端串口初始化

### 2.1 串口配置函数

```cpp
#include <sys/types.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <termios.h>

int Serial_Init(const char *devpath, int baudrate)
{
    int fd;
    struct termios oldtio, newtio;

    // 1. 打开串口设备
    fd = open(devpath, O_RDWR | O_NOCTTY | O_NONBLOCK);
    if (fd == -1) {
        perror("serial->open");
        return -1;
    }

    // 2. 保存当前设置
    tcgetattr(fd, &oldtio);

    // 3. 配置新参数
    memset(&newtio, 0, sizeof(newtio));
    newtio.c_cflag = baudrate | CS8 | CLOCAL | CREAD;  // 波特率+8数据位+本地+接收使能
    newtio.c_iflag = IGNPAR;   // 忽略奇偶校验错误
    newtio.c_oflag = 0;
    newtio.c_lflag = 0;        // 非规范模式（raw mode）

    newtio.c_cc[VTIME] = 1;    // 超时 0.1秒
    newtio.c_cc[VMIN] = 36;    // 最少读取36字节

    // 4. 清空缓冲区并应用设置
    tcflush(fd, TCIFLUSH);
    tcsetattr(fd, TCSANOW, &newtio);

    return fd;
}
```

### 2.2 串口标志位说明

| 标志 | 含义 |
|------|------|
| `O_RDWR` | 读写模式 |
| `O_NOCTTY` | 不将此设备作为控制终端 |
| `O_NONBLOCK` | 非阻塞模式 |
| `CS8` | 8位数据位 |
| `CLOCAL` | 忽略调制解调器控制线 |
| `CREAD` | 使能接收器 |
| `IGNPAR` | 忽略帧错误和奇偶校验错误 |

### 2.3 调用方式

```cpp
// 在主窗口初始化时调用
int myserial = Serial_Init("/dev/ttySAC2", 9600);

// ARM开发板使用 /dev/ttySAC2 (Samsung SoC的串口设备)
// x86桌面可改为 /dev/ttyUSB0 或 /dev/ttyS0
```

## 三、串口读写操作

### 3.1 写入命令

```cpp
char buf[10] = {0};
strcpy(buf, "open");
write(myserial, buf, sizeof(buf));  // 发送"open"命令到STM32
```

### 3.2 读取响应

```cpp
char r_buf;
int r_len = read(myserial, &r_buf, sizeof(r_buf));

if (r_len < 0) {
    qDebug("read error\n");
}

// 解析响应
if (r_buf == 0x01) {
    QMessageBox *box = new QMessageBox(QMessageBox::Information,
        QString("结果提示"), QString("门已开启"));
    QTimer::singleShot(2000, box, &QMessageBox::close);
    box->exec();
}

if (r_buf == 0x02) {
    QMessageBox *box = new QMessageBox(QMessageBox::Information,
        QString("结果提示"), QString("门已关闭"));
    QTimer::singleShot(2000, box, &QMessageBox::close);
    box->exec();
}

// 清空缓冲区
memset(&r_buf, 0, sizeof(r_buf));
```

## 四、STM32 端实现

### 4.1 串口接收与命令解析

```c
// UART4 中断接收
void UART4_IRQHandler(void) {
    if (USART_GetITStatus(UART4, USART_IT_RXNE) != RESET) {
        uart4_buff[uart4_cnt++] = USART_ReceiveData(UART4);
    }
    // IDLE中断检测帧结束
}

// 命令检查函数（主循环调用）
void Data_Check(void) {
    if (uart4_cnt == 0) return;

    // 检查是否收到 "open" 命令
    if (strstr((const char*)uart4_buff, "open") != NULL) {
        // 触发开门
        door.count = 90 * 64 / 5.625;  // ~1024步 = 90度
        door.motor_dir = 1;             // 正转
        door.door_state = 1;            // 开门中
        Uart4_Tx(0x01);                // 回复: 门已开启
        memset(uart4_buff, 0, sizeof(uart4_buff));
        uart4_cnt = 0;
    }
}
```

### 4.2 手动按键控制

```c
// 按键扫描
uint8_t key_value = Xyd_Key_Scan();

if (key_value == 1) {   // KEY1: 开门
    door.count = 90 * 64 / 5.625;  // 90度步数
    door.motor_dir = 1;             // 正转
    door.door_state = 1;            // 开门状态
    Uart4_Tx(0x01);
} else if (key_value == 2) {  // KEY2: 关门
    door.count = 90 * 64 / 5.625;
    door.motor_dir = 0;             // 反转
    door.door_state = 2;            // 关门状态
    Uart4_Tx(0x02);
}
```

## 五、通信协议定义

| 方向 | 数据 | 含义 |
|------|------|------|
| ARM → STM32 | `"open"` | 识别成功，请求开门 |
| STM32 → ARM | `0x01` | 门已开启 |
| STM32 → ARM | `0x02` | 门已关闭 |

## 六、非阻塞串口的重要性

```cpp
fd = open(devpath, O_RDWR | O_NOCTTY | O_NONBLOCK);
```

`O_NONBLOCK` 使得 `read()` 调用立即返回，不会阻塞GUI线程：
- 没有数据可读时返回 -1（errno = EAGAIN）
- 配合 `VTIME` 和 `VMIN` 控制超时行为
