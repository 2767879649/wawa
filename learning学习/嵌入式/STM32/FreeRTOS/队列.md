# 队列
--如果使用了队列集，必须先等待队列集有数据，再接收队列
*队列发送数据要确保数据真的发送了*
1. 创建队列(`xQueueCreate(3, sizeof(int));`)
2. 创建队列集(`xQueueCreateSet(2);`)
3. 将队列放在队列集中(`xQueueAddToSet(xQueueHandle1, xQueueHandle3);`)
4. 创建任务()
5. 队列发送数据 `xQueueSend(xQueueHandle1, &a, portMAX_DELAY);`
6. 队列接收数据 `xQueueReceive(xQueueHandle1, &i, 0);`
7. ```c
   //队列集接收数据
        QueueSetMemberHandle_t handle;
   -----
       handle = xQueueSelectFromSet(xQueueHandle3, portMAX_DELAY);//等待一个队列中有数据
       xQueueReceive(handle, &i, 0);//接收数据
       printf("%d\r\n", i);
   ```
