# 轻量级信号量
1. 发送通知(不阻塞) `xTaskNotifyGive(taskhandle);`，发送通知会让结构体里的计数值值+1
2. 接收通知`val = ulTaskNotifyTake(pdFALSE, portMAX_DELAY);`直到计数值等于1结束，pdTRUE直接让计数值清零

# 轻量级队列
只能接收一个数据，在发送通知时，选择覆盖或者不覆盖
1. 发送通知 `xTaskNotify(taskhandle, a, eSetValueWithOverwrite);` eSetValueWithOverwrite 覆盖
eSetValueWithoutOverwrite 不覆盖
2. 接收通知 `xTaskNotifyWait(0, 0, &val, portMAX_DELAY);` //选择在接收前舍弃某位，在 val 出来前舍弃某位，不选择就是 0；
