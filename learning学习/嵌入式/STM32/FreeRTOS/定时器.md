# 定时器
可以用来按键消抖
1. 创建定时器 `Mytimehandle = xTimerCreate("time1", 200, pdFALSE, NULL, MytimeCallbackFunction);` //定时器任务，ARR，是否重装，定时器 ID，回调函数 
2. 创建回调函数 `void MytimeCallbackFunction(TimerHandle_t Timer)`
3. 在任务中开启定时器`xTimerStart(Mytimehandle, 0);`

中断重启定时器
```c
BaseType_t xHigherPriorityTaskWoken = pdFALSE;               // 设置标志位
 xTimerResetFromISR(Mytimehandle, &xHigherPriorityTaskWoken); // 触发定时器重启,更改标志位
 portYIELD_FROM_ISR(xHigherPriorityTaskWoken);                // 切换任务
```
