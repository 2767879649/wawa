# 信号量
1. 定义结构句柄`static SemaphoreHandle_t xSemCalchandle;`
2. 创建计数型信号量 `xSemaphoreCreateCounting(10, 0);`
3. 创建二进制型信号量 `xSemaphoreCreateBinary();`，先把信号量置 1；
4. 发送信号量 `xSemaphoregive(xSemchandle);`
5. 获得信号量 `xSemaphoretake(xSemchandle, portMAX_DELAY);`

# 互斥量
1. 创建互斥锁 `xSemaphoreCreateMutex()` //与二进制用法一致，有<font color="#9bbb59">优先级继承</font>
2. 创建递归锁`xSemaphoreCreateRecursiveMutex();`//只有自己才能开锁，别人不能开锁，可以二次获取锁
