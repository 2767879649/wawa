
## 建立一个工程
### **新建工程步骤**
1.  建立工程文件夹，Keil中新建工程，选择型 号
2. 工程文件夹里建立Start、Library、User等文件夹，复制固件库里面的文件到工程文件夹
3. 工程里对应建立Start、Library、User等同名称的分组，然后将文件夹内的文件添加到工程分组里[[工程文件]]
4. 点击魔术棒工程选项，C/C++，Include Paths内声明所有包含头文件的文件夹(目的：变为只读文件，不更改）
5. 工程选项，C/C++，Define内定义输入 <mark style="background:#d3f8b6">`USE_STDPERIPH_DRIVER`</mark> (<font color="#76923c">使用库函数必须加入这个，否则库函数无法使用</font>)
6. 工程选项，Debug，下拉列表选择对应调试器，Settings，Flash Download里勾选Reset and Run
### 芯片选择

| 缩写    | 释义        | Flash容量  | 型号                |

| MD_VL | 中容量产品超值系列 | 64~128K  | STM32F100         |
| HD_VL | 大容量产品超值系列 | 256~512K | STM32F100         |
| LD    | 小容量产品     | 16~32K   | STM32F101/102/103 |

| CL    | 互联型产品     | -        | STM32F105/107     |
