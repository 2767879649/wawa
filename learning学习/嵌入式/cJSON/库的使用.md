## cJSON 打包数据
1.  `cJSON *root = cJSON_CreateObject();`               // 创建一个新的JSON对象
2.  `cJSON_AddStringToObject(root,"name","xiaoming")` //添加字符串键值
`cJSON_AddNumberToObject(root, "age", 30);` //添加数字键值
4.  `char *json_string = cJSON_Print(root);` //将 JSON 对象转换为字符串
5.  `cJSON_Delete(root)`  //释放 JSON 对象占用的内存
`cJSON_free(json_string)` //释放 cJSON_Print 分配的内存


## cJSON 解析数据
1. `cJSON_Parse` //解析字符串
2. `cJSON *results = cJSON_GetObjectItem(root, "results");` //定义一个 JSON 对象，来接收 root 中的成员
3. `cJSON *first = cJSON_GetArrayItem(results, 0);` //定义一个 JSON 对象，来接收 results 数组对象中第一个成员
